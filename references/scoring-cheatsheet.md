# 分值口径速查（模板，务必以手上细则为准）

这份表是"读细则时该抄下什么"的骨架。**不要照抄本表当作真实规则**——每个学院、每个学年的档次与上限都可能不同，逐条从细则原文誊写。

## 一、总分结构

```
综合素质测评成绩 = 思想道德×w1 + 科学文化×w2 + 身心健康×w3 + 人文艺术×w4 + 劳动技能×w5 + 附加分
```

读细则第一件事：抄下五个权重和"附加分是否封顶"。

## 二、每一素质项的分工（常见写法）

| 素质项 | 通常拆成 | 需要抄下的字段 |
|---|---|---|
| 思想道德素质 | 基础分 + 民主测评分 + 发展分 | 荣誉档次表（集体/个人 × 国家/省部/校/院）、是否取最高不累加 |
| 科学文化素质 | 基础分（课程优秀率）+ 发展分（创新创业项目、学术交流） | 项目结项等级对应分值、讲座/会议/交流的计次规则与启动阈值 |
| 身心健康素质 | 基础分（体测）+ 发展分（体育/心理赛事） | 个人/团体 × 级别 × 名次的四维表、**趣味项目是否减半**、参与分上限 |
| 人文艺术素质 | 基础分（演出/展览按次）+ 发展分（比赛、晚会、表演） | 每次分值、基础分上限、比赛档次表、校/院大型晚会与"非首次表演减半" |
| 劳动技能素质 | 基础分（社会实践/志愿服务/宣讲/学生工作）+ 发展分 | 队长-队员分差、志愿时长单价与上限、学生工作三档名单、发展分"由领导小组认定 ≤N 分" |
| 附加分 | 学术创新（论文/专利/软著）+ 学科竞赛 + 创新创业项目 | 竞赛级别认定表（国A/国B/省A/省B/校/院 × 名次）、各类封顶值 |

## 三、定分时最容易踩的六个坑

1. **同一材料两种归类**：课程类/思政类比赛，既可算"学科竞赛"（分值低、进附加分封顶），也可算"文化艺术比赛"（分值高、进人文艺术发展分）。**问用户**。
2. **计次阈值**："超过 N 次后每参加 1 次加 X 分"——阈值前的次数不产生分数，别按"每次 X 分"算。
3. **累加 vs 取最高**：学生工作多岗、同类型荣誉、同一比赛不同级别，细则常有一句"取最高不累加"或"可累加"，务必找到那句。
4. **减半条款**：趣味项目、非首次表演、不满一年任期——常被漏读，漏了就是虚报。
5. **封顶条款**：学术创新"上不封顶"、学科竞赛"封顶 5 分"、志愿服务"≤40 分"、基础分"≤80 分"，逐个记住。
6. **证据与口径不一致**：自述 5 次讲座但学院公示只勾了 3 次。按"能被证明的次数"填，或在说明里写清依据，别静默取大。

## 四、证据侧的要求（常写在附则里）

- 材料须加盖单位印章，否则视为无效；
- 论文/专利以录用通知或证书为准；竞赛以主办方公示/证书为准；
- 荣誉称号"未列出的可举证由领导小组认定"——这类可以填，但要在说明里点明"经认定"；
- 同一项目多项荣誉只取最高。
