# 输出格式与踩坑清单

## A. 明细表 xlsx

结构（与学院模板同构，仅替换内容）：

```
R1-R3   合并标题（方正小标宋/黑体 20pt 加粗居中）
R4-R5   班级：<班级>      姓名：<姓名>      学号：<学号>
R6      所属类别 | 项目 | 加分分值（100分制）        ← 黑体 11 加粗 + 细边框
R7...   类别列 A 纵向合并、子类列 B（基础分/发展分）纵向合并
R末-1   学生签字（手写）：                    ← 左侧合并跨两行、右列留空
R末     注：请出具相关的证明…并按照上述顺序依次排序。 ← 整行合并
```

要点：

- **列宽沿用模板**（常见 A≈21.6 / B≈12 / C≈51.6 / D≈33.4）；**行高随行数走**：单行 20、两行 30（自动两倍）、三行 45，由 `est_height()` 按 C 列文本视觉宽度估算，长项目名不允许被压成一行；
- 类别列与子类列用**连续同值即合并**的规则自动推导，见 `scripts/build_detail_xlsx.py`；
- 项目列左对齐 + 自动换行，分值列居中；
- 数值可以是小数（如志愿时长 × 单价），不要四舍五入掉；
- 模板里的示例行（"校级优秀三好学生""XX 讲座"之类）全部替换，一个不留。

## B. 佐证材料汇编 docx

```docx
（居中）<学院名称>
（居中）综合测评佐证材料
（居中）姓名：<姓名>　学号：<学号>　班级：<班级>
（居中）以下材料按《…明细表（个人提交）》填报顺序编号

【1】<类别>·<子类>——<一行说明>
        [居中图片]
【2】…
```

要点：

- 每条说明**一行写完**，包含：类别归属、项目全名、等级/名次/时长、必要的出处（附件名 + 页号/序号）；
- 图片居中，横图 15cm、竖图 11cm；
- 编号必须与明细表项目顺序一一对应；"无需佐证"的条目保留编号不配图；
- 文档体积：20 张图压缩后约 4-5MB，超过 10MB 说明压缩没生效。

## C. 用户偏好（默认沿用，可在会话中调整）

| 偏好 | 说明 |
|---|---|
| 顺序＝填表顺序 | 类别序从上到下，不是按材料收集顺序、也不是按"证书在前" |
| 多项目大块保留小计行 | 如"小计（基础分上限50分）"＝50、"小计（基础分上限80分）"＝65.75、"小计（学科竞赛类封顶5分）"＝2.2，小计行括号里写清口径 |
| 按次计分项逐条列、逐行写分值 | 如讲座 5 次 → 5 行，未达阈值写 0、触发那次写档位分（0/0/0/0/5） |
| 项目文字简洁 | 等级写到"三等奖"即可，少加括号备注 |
| 行高随行数 | 单行 20、两行 30、三行 45，别把长项目名压成一行 |
| 不加表情符号 | 表与文档里都不要 emoji、装饰符号 |
| 无需佐证的项照常编号 | 说明里注明"（无需佐证材料）"，不配图 |
| 不覆盖原件 | 产物是新文件，命名带"（已填写）" |

## D. 提交前自检

1. 读回 xlsx：`openpyxl` 打印所有非空单元格 + 合并区，逐项核对分值与序号；
2. 读回 docx：打印每条说明与图片数，核对编号连续、图片没串位；
3. 正则扫描两个文件的禁写内容：
   ```python
   emoji = re.compile('[\U0001F300-\U0001FAFF\U00002600-\U000027BF\uFE0F]')
   ```
4. 小计行的口径与分值自洽（各明细项相加＝小计），并搜索残留占位：`小记`、`XX`、`示例`、`（待定）`；
5. 确认产物路径下没有 `~$` 前缀的 Office 锁文件同名冲突。

## E. 踩坑记录

| 现象 | 原因 | 处理 |
|---|---|---|
| 写入后用户看到的还是旧内容 | 文件正被 Word/Excel 打开，工作区出现 `~$xxx` 锁文件 | 提醒用户关闭再重开；不要删锁文件 |
| 明细表改一处结果全表错行 | 直接在带示例行的模板上插删行 | 用脚本按 `rows` 重建，比较结构稳定 |
| docx 体积几十 MB | 手机原图直接插入 | 插入前统一 `thumbnail((1600,1600))` + `quality=82` |
| 图片在文档里躺倒 | 忽略 EXIF 方向 | `ImageOps.exif_transpose` |
| 扫描件 grep 不到任何内容 | 无文本层 | OCR 定位 + 渲染命中页 |
| 只找到"参赛名单"却找不到名次 | 报名/检录材料不含成绩 | 按"参与"档填报，并提示用户补成绩公告以升级档位 |
| 同一队在两个项目里人数不同 | 检录表按项目分行 | 逐项目核对本人编号所在行 |
